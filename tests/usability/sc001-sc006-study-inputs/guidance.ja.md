# Inspector の使い方

[English](guidance.md)

このツールについて伝えられるのは、ここに書いてあることだけです。モデレーターがこれ以上説明する
ことはありません。

## 起動する

渡されたフォルダの `repository/` ディレクトリでターミナルを開き、次を実行します。

```bash
npx --no-install agent-customization-inspector --no-open
```

コマンドがURLを表示します。それを、このセッション用に用意されたブラウザに貼り付けてください。

## 表示されるもの

1ページに、そのディレクトリで Claude Code、GitHub Copilot、OpenAI Codex が探すカスタマイズ
ファイルが並びます。

左に種類と件数が並びます。種類を選ぶと、その行が右に出ます。行を選ぶと、そのファイルが開きます —
全文と、そこに書かれた宣言です。

一覧に載っていることは、そのツールがそのファイルを読み込んだという意味ではありません。ページが
示すのは、何が置いてあって何と書いてあるかです。

## 終了する

ターミナルで Ctrl+C を押します。
