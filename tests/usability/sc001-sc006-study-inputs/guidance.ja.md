# Inspector の使い方

[English](guidance.md)

このツールについて伝えられるのは、ここに書いてあることだけです。runnerがこれ以上説明する
ことはありません。

## 起動する

渡されたフォルダの `repository/` ディレクトリでターミナルを開き、次を実行します。

```bash
npx --no-install agent-customization-inspector --no-open
```

コマンドがURLを表示します。それを、このセッション用に用意されたブラウザに貼り付けてください。

## 表示されるもの

1ページに、そのディレクトリで Claude Code、GitHub Copilot、OpenAI Codex が探すカスタマイズ
ファイルが並びます。

左に種類と件数が並びます。種類を選ぶと、その行が右に出ます。1行が何を指すかは種類によります。
ファイルのこともあれば、複数のファイルが共有しうる名前や宣言されたイベントのこともあります。
行を選ぶと、それが指すものが開きます。ファイル自身のページはその全文と、そこに書かれた宣言を
持ちます。宣言のページはその宣言と、それが書かれた各ファイルへの導線を持ちます。

一覧に載っていることは、そのツールがそのファイルを読み込んだという意味ではありません。ページが
示すのは、何が置いてあって何と書いてあるかです。

## 終了する

ターミナルで Ctrl+C を押します。
