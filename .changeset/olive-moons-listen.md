A plugin detail page no longer announces "Plugin ready." when it finishes loading. Every kind is silent on arrival, as the other ten already were: focus is already on the page's heading, which has named the subject, and the session has already been announced as ready — a second "ready" says only that something changed, not what it changed into.

A skill detail page reached by a link whose file its directory no longer holds now announces that, rather than announcing that nothing sits at the link's path. The screen has drawn those as two different states all along; a reader who cannot see it was told the skill itself was gone.
