The detail page you land on when you open a customization — a skill, an instruction file, a prompt or command, a custom agent, a hook, an MCP server, a plugin, a rule, an output style, a permission policy, a settings file — now builds its trail back to the list, its line of facts about the file, the note naming the directory the file was read from, and what a screen reader is told while the page loads or fails from one shared implementation. Nothing looks or sounds different from the previous release; the eleven pages can no longer drift into saying the same thing eleven ways.
